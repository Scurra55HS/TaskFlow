# TaskFlow

TaskFlow é um gerenciador de tarefas em estilo **Kanban**, criado para organizar atividades de forma simples, visual e eficiente.

O projeto foi desenvolvido com **HTML, CSS e JavaScript puro**, sem bibliotecas externas, com foco em clareza, usabilidade e conclusão rápida.

---

## Funcionalidades

-  Adicionar novas tarefas
-  Arrastar tarefas entre colunas (Drag & Drop)
-  Excluir tarefas
-  Salvamento automático com `localStorage`
-  Layout responsivo (desktop e mobile)

---

##  Organização das tarefas

As tarefas são organizadas em três colunas:

- **A Fazer**
- **Em Andamento**
- **Concluído**

Basta arrastar uma tarefa de uma coluna para outra para atualizar seu status.

---

##  Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- LocalStorage (persistência de dados no navegador)
